# Agua Amazonas - Sistema de Gestión de Pedidos y Repartos
Sistema web para el procesamiento de pedidos de agua embotellada en Caranavi - Yungas.

## Tecnologías utilizadas
- **Backend:** Node.js, Express.js
- **Base de Datos:** MariaDB / MySQL
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Procesos:** PM2

## Estructura del Proyecto
- `/public/index.html` - Interfaz para clientes y pedidos en línea.
- `/public/admin.html` - Panel de administración y creación de repartidores.
- `/public/repartidor.html` - Panel para choferes y repartidores.
- `server.js` - Servidor Express y API REST.
